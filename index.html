TRES PASOS. UN SOLO PUSH.

01 / CÓDIGO+ Todo empieza con un cambio. Escribes, guardas y haces push a main. GitHub Actions toma el relevo.

El workflow se activa con cada push a la rama main. Primero descarga el código del repositorio en una máquina temporal.

02 / INTEGRACIÓN+ Una comprobación antes de salir. El pipeline verifica el contenido y empaqueta la página para publicarla.

La prueba busca el texto Hola Mundo en index.html. Si lo encuentra, prepara el artefacto del sitio. Si falla, el proceso se detiene.

03 / DESPLIEGUE+ Y entonces, Hola mundo. GitHub Pages publica el resultado. Tu idea ya tiene un lugar en internet.

El despliegue espera a que la integración termine correctamente. Después, publica el artefacto en GitHub Pages de forma automática.
